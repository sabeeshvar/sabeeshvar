## 🚀 Featured Projects

### 🌟 THULIR — AI-Powered Mine Subsidence Monitoring & Early Warning System (SIH 2026)
THULIR is an AI-powered T-shaped mine subsidence monitoring and early-warning system designed for underground coal mining. It leverages a localized wireless surface mesh sensor network to monitor ground conditions and detect potential subsidence risks.
- **Technologies:** ESP32, A7670C 4G, Flask, Isolation Forest, Random Forest
- **Sensors:** MPU6050 (Tilt), ADXL345 (Vibration), HC-SR04 (Distance), Flex Sensor (Crack/Bending), Soil Moisture, DHT22
- **Features:** GIS/Map visualization, live monitoring dashboard, automated alerts, solar + battery power
- **Impact:** Low-cost target of ~₹3,035 per node
